Entry for the make.fun bounty "One Emoji, One Smile": a pure-stdlib Python program that writes exactly one emoji — 🤗 HUGGING FACE — and nothing else to `/output/entry.txt`. A smiling face with open arms offering a hug: warm at first glance, understood the same way at any age, a deliberate pick rather than the first smiley that comes to mind, and right coming from a stranger — no intimacy, no sarcasm, no flirtation.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`). The program validates its own output before writing: exactly one emoji grapheme, 1–8 characters, UTF-8. Two runs are byte-identical.
